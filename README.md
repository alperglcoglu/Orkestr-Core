# Orkestr

Orkestr, Claude Code için otonom bir "AI şirketi" plugin'idir: planlama, toplantılar, sınırlı ve paralel geliştirme dalgaları, kanıta dayalı review'lar, durum raporları ve retrospektifler.

- Plugin ve kurulum: [plugins/orkestr/README.md](plugins/orkestr/README.md)
- Vizyon ve tam spesifikasyon: [MASTER_SPEC.md](MASTER_SPEC.md)
- Faz 1 uygulama planı: [PHASE1_IMPLEMENTATION.md](PHASE1_IMPLEMENTATION.md)

## Hızlı kurulum

Claude Code içinde:

```
/plugin marketplace add alperglcoglu/Orkestr
/plugin install orkestr@orkestr
```
